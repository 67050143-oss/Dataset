# Dataset folders

Use these folders to collect hand gesture data for the robotic arm project.

Folders:
- idle
- left
- right
- near
- far
- grip

Recommended workflow:
1. Open the preview app or data collection script.
2. Keep the webcam in the same angle and lighting as the real use case.
3. Save multiple samples per label.
4. Keep only clear images or landmark samples, no blurred or ambiguous ones.
5. After collecting enough data, run the training script.
